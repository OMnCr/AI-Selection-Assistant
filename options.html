AI Selection Assistant

Select text, use a shortcut plus 1/2/3…, and stream the AI response.

API configuration

Works with OpenAI-compatible Chat Completions APIs. Enter the URL through /v1, or paste a full /chat/completions endpoint.

After entering a Base URL, you can fetch the models supported by this API.

For example, Alt + number makes Alt+1 use the first prompt. Some combinations may be reserved by the browser, such as Ctrl + number for switching tabs.

Prompt shortcuts

Items 1–9 map to shortcut + 1 through shortcut + 9. Use {{selection}} where the selected text should appear. If omitted, the selection is appended to the end.
